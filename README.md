# Kulturhus Event Sync

Dieser private Dienst liest ausschliesslich die kommenden, von Kulturhus Jaderberg e. V. veranstalteten Facebook-Events:

https://www.facebook.com/kulturhusjaderberg/upcoming_hosted_events

Die GitHub Action startet nur manuell oder ueber das Signal `eventbrite_changed`. Zugangsdaten gehoeren ausschliesslich in GitHub Secrets und niemals in dieses Repository.
